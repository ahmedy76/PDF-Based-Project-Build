## Guidelines

Design the app UI in a Modern SaaS style inspired by Linear, Stripe, and Notion. Create subtle depth using layered shadows. Use a refined color palette with neutral grays and vibrant accent colors with subtle gradients (primary gradient success: green, warning: orange/yellow, error: red). Apply smooth, generous rounded corners: small, medium, large, extra-large. Buttons should be sophisticated with multiple variants: primary (gradient fill, white text, no border), secondary (white/transparent fill, 1px border, subtle shadow on hover), ghost (transparent, color change on hover). Include micro-interactions: smooth transitions, scale on click (0.98), subtle hover states. Typography uses Inter or similar modern sans-serif. Cards have white backgrounds with subtle borders and soft shadows, hovering slightly on interaction. Include modern patterns: keyboard shortcuts displayed as kbd tags, command palettes (cmd+k), inline code with background, syntax-highlighted code blocks. Navigation should be minimal with icon+text combos, breadcrumbs. Add delightful details: animated gradients on key elements, skeleton loaders, smooth page transitions. The interface should feel fast, modern, delightful, and premium - perfect for SaaS products, developer tools, and modern business applications. If not provided, pick a random primary modern color from the tailwind palette
